# 요구사항 정의

- 최종 수정: 2026-11-10 (순서 조정 구현 반영)
- 관련: [roadmap.md](roadmap.md) · [architecture/overview.md](../architecture/overview.md) · [platform-notes.md](../architecture/platform-notes.md)

## 1. 한 줄 정의

메뉴바에 상주하면서 **어떤 앱의 아이콘을 메뉴바에 보일지 고르고, 클릭 한 번으로 숨긴 앱을 펼쳤다 접고, 순서를 정리**해 주는 macOS 앱.

## 2. 용어

| 용어 | 뜻 |
|---|---|
| 메뉴바 아이템 | 메뉴바 오른쪽에 표시되는 아이콘 하나 (`NSStatusItem`). 한 앱이 여러 개를 가질 수 있음 |
| 관리 대상 앱 | 메뉴바 아이템을 가진 앱. 표시/숨김의 단위 |
| 시스템 아이템 | 시계, 제어 센터, Wi-Fi, 배터리 등 macOS가 제공하는 아이템 |
| 이 앱의 아이콘 | 메뉴바에 있는 이 앱 자신의 아이콘. 좌클릭·우클릭의 대상 |
| 펼치기 / 숨기기 | 숨긴 앱을 전부 보이게 함 / 설정대로 다시 숨김 |
| 메뉴바 관리 | 설정 창의 첫 탭. 앱별 표시 여부와 순서를 정하는 화면 |
| 레이아웃 | 표시 여부 + 순서를 합친 설정 한 벌 |

## 3. 사용 방식 (상호작용)

| 입력 | 동작 |
|---|---|
| 이 앱의 아이콘 **좌클릭** | 숨긴 앱 **펼치기 ↔ 숨기기** |
| 이 앱의 아이콘 **우클릭** (Control+클릭) | 메뉴: **숨기기 스위치** · 설정… · **정보** · 종료 |
| 메뉴 > **설정…** | 설정 창 → **메뉴바 관리**에서 앱 선택·순서 조정, "펼친 뒤 자동으로 다시 숨기기" 등 옵션 |
| 메뉴 > **정보** | 주요 기능의 간략한 설명 (메뉴바 아이콘 옮기는 방법 포함) |

결정 배경은 [ADR-0009](../adr/0009-interaction-model.md).

## 4. 기능 요구사항

우선순위: **P0** = MVP 필수, **P1** = MVP 직후, **P2/P3** = 이후.
실현성: ✅ 이 Mac에서 검증됨 · 🟢 공개 API(위험 낮음) · ⏳ 검증 대기
구현: 🔨 제품 코드에 구현됨 (2026-11-10 기준)

### 필수 (사용자 요청)

| ID | 요구사항 | 우선순위 | 마일스톤 | 실현성 |
|---|---|---|---|---|
| FR-1 | 메뉴바에 표시할 앱을 선택한다 (앱별 표시/숨김) | P0 | M2 | ✅ 🔨 |
| FR-2 | 이 앱의 아이콘 **좌클릭**으로 숨긴 앱을 펼치고 숨긴다 | P0 | M2 | ✅ 🔨 |
| FR-3 | 메뉴바 아이템의 순서를 조정한다 | P0 | M3 | ✅ 🔨 |
| FR-3a | 숨겨진 앱의 순서도 조정한다 (펼쳤을 때 나타나는 순서) | P0 | M3 | ✅ 🔨 |
| FR-4 | 컴퓨터 시작(로그인) 시 자동으로 실행된다 | P0 | M1 | ✅ 🔨 재부팅 후 자동 실행·숨김 재적용 확인 |
| FR-16 | 이 앱의 아이콘 **우클릭** 메뉴에서 **숨기기를 스위치로 켜고 끄며**, 설정에 접근한다 | P0 | M1 | ✅ 🔨 |

| FR-20 | 우클릭 메뉴의 **"정보"** 에서 주요 기능을 간략히 설명한다 (메뉴바 아이콘 옮기기 포함) | P0 | M1 | ✅ 🔨 |

### 수용 기준

**FR-1 표시할 앱 선택**
- 설정 > 메뉴바 관리에서 앱별로 표시/숨김을 바꿀 수 있다.
- 바꾸면 1초 이내에 메뉴바에 반영된다. 깜빡이지 않는다.
- 설정은 재시작·재부팅 후에도 유지된다.
- 이 앱 자신의 아이콘과 보호 대상 시스템 아이템(시계, 제어 센터)은 숨길 수 없다.
- 숨길 수 없거나 표시할 수 없는 앱에는 이유가 표시된다 (예: 응용 프로그램 폴더 밖에 있는 앱).

**FR-2 좌클릭 — 펼치기/숨기기**
- 좌클릭 한 번에 숨긴 아이템이 모두 나타나고, 다시 누르면 숨는다.
- 이 앱의 아이콘 모양이 현재 상태(펼침/숨김)를 나타낸다.
- 설정의 "펼친 뒤 자동으로 다시 숨기기"가 켜져 있으면 지정 시간 뒤 자동으로 숨는다. **시간은 설정에서 고른다 (3·5·10·15·30·60초, 기본 10초).**
- 나타난 아이템의 메뉴를 쓰는 동안(어떤 메뉴든 열려 있거나 포인터가 메뉴바 위에 있을 때)에는 숨기지 않고, 2초마다 다시 확인해 끝나면 숨긴다. 🔨
- 어떤 경우에도 이 앱의 아이콘은 사라지지 않는다.

**FR-3 순서 조정**
- 설정 > **순서** 탭에서 "메뉴바에서 순서 읽기"를 누르면 현재 순서가 목록으로 나온다 (위가 왼쪽). 숨긴 앱도 "숨김" 표시와 함께 포함된다. 🔨
- 목록을 드래그해 순서를 바꾸고 "적용"을 누르면 실제 메뉴바 순서가 같게 바뀐다. 🔨
- 시스템 항목(시계, 제어 센터 등)은 옮길 수 없지만, 그 사이로 다른 아이콘을 옮길 수 있다. 🔨
- 접근성 권한이 없으면 이유와 요청 버튼을 보여 준다. 🔨
- 실패하면 목록이 실제 순서로 되돌아가고 알려 준다. 🔨
- 읽기·적용 중에는 숨긴 아이콘이 잠깐 나타나고, 적용 중에는 포인터가 잠깐 움직인다 (화면에 안내).
- (미구현) 메뉴바 관리의 "표시"·"숨김" 구역 사이를 드래그해 표시 여부 바꾸기 — 지금은 스위치로 바꾼다.

**FR-4 로그인 시 실행**
- 설정 > 일반의 "로그인 시 실행" 스위치로 제어한다.
- 첫 실행 때 설정 창이 열리고 "시작하기" 안내에서 바로 켤 수 있다. 🔨

**FR-16 우클릭 메뉴**
- 우클릭 또는 Control+클릭으로 열린다.
- 항목: **숨기기 (스위치)** · 설정… · 정보 · 종료. 이후 프로필 전환(M5)이 추가된다.
- 스위치는 현재 상태를 보여 준다 (켬 = 숨김 적용 중, 끔 = 전부 표시).
- 스위치를 켜면 즉시 숨기고, 끄면 전부 표시한 채로 **유지한다.** 스위치로 끈 경우에는 자동으로 다시 숨기지 않는다 (좌클릭으로 잠깐 펼친 경우와 다름).
- "펼친 뒤 자동으로 다시 숨기기"는 이 메뉴에 두지 않고 설정 창에 둔다.

**FR-20 정보**
- 우클릭 메뉴 > 정보를 누르면 설명 화면이 열린다.
- 다음을 각각 한두 문장으로 설명한다: 숨긴 앱 펼치기/숨기기(좌클릭) · 숨기기 켜고 끄기(우클릭 스위치) · 숨길 앱 고르기(설정) · 자동으로 다시 숨기기 · **메뉴바 아이콘 옮기기** · 알아 둘 점(표시할 수 없는 경우, 종료 시 복구).
- 메뉴바 아이콘 옮기기는 "⌘을 누른 채 아이콘을 드래그"하는 방법을 안내한다. 숨긴 앱은 펼친 뒤 옮긴다고 알려 준다. 설정 창에서의 드래그 정렬(FR-3)이 들어가면 그 방법을 함께 적는다.
- 앱 버전을 표시한다.
- 기능이 바뀌면 이 설명도 같이 고친다.

**FR-17 설정 창 — 메뉴바 관리**
- 설정 창을 열면 메뉴바 관리 탭이 먼저 보인다.
- **검색**: 앱 이름으로 즉시 걸러진다.
- **필터**: 메뉴바에 있는 앱 / 숨긴 앱 / 설치된 앱 전체.
- 기본 보기는 "현재 메뉴바에 아이콘이 있는 앱"만 보여 목록이 짧다. 설치만 되어 있고 실행 중이 아닌 앱은 검색·필터로 찾아 미리 지정할 수 있다.
- 표시 구역·숨김 구역으로 나뉜다 🔨. 각 구역 안의 순서를 메뉴바 순서로 맞추는 것은 순서 조정(FR-3)과 함께.
- "펼친 뒤 자동으로 다시 숨기기"(켬/끔, 시간)는 설정 창의 **일반** 탭에서 설정한다.
- 창 크기를 조절할 수 있고 키보드로 탐색할 수 있다.

| FR-9 | **설정 백업/복원** — 숨길 앱 목록·옵션을 JSON으로 내보내기·가져오기 🔨 | 재설치·다른 Mac 이전, 실수 복구 | P1 | M4 |
| FR-19 | **시스템 아이콘 숨김** — Wi-Fi·배터리를 숨김 대상에 포함 (시계·제어 센터는 항상 표시). 설정 > 메뉴바 관리의 "시스템 아이콘" 구역에서 고름 🔨 | 번호로 개별 제어 가능함을 확인 (검증됨) | P1 | M4 |

| FR-13 | **조건부 표시** — "앱이 실행 중일 때만" 등 | 필요할 때만 보이기 | P3 | M5 |

## 5. 비기능 요구사항

| ID | 요구사항 | 기준 |
|---|---|---|
| NFR-1 | **안전** | 어떤 오류에서도 메뉴바가 "전부 표시"로 돌아갈 수 있어야 함. 이 앱의 아이콘은 항상 보여야 함 |
| NFR-2 | **권한 최소화** | 숨김·펼치기는 권한 없이 동작 (검증됨). 접근성 권한은 순서 탭을 쓸 때만 요청 🔨 |

| NFR-5 | **프라이버시** | 네트워크 통신 없음 (자동 업데이트 도입 전까지). 화면 내용 저장 안 함 |
| NFR-6 | **접근성·현지화** | VoiceOver 레이블 제공. 한국어 원문 + 영어 번역 (문자열 139개, `scripts/strings.py check`로 누락 검사) 🔨 |
| NFR-7 | **목록 규모** | 메뉴바 관리 화면이 앱 300개에서도 검색·스크롤이 끊기지 않음 |

## 6. 범위 밖 (하지 않는 것)

- 데스크탑/알림 센터에 놓는 WidgetKit 위젯 ([ADR-0001](../adr/0001-menu-bar-agent-app.md))
- 메뉴바 아이콘을 눌렀을 때 열리는 패널(팝오버) — 관리 화면은 설정 창으로 ([ADR-0009](../adr/0009-interaction-model.md))
- macOS 26 이하용 별도 숨김 방식 — 앱은 macOS 15부터 실행되지만 숨김은 시스템 기능이 있는 버전에서만 동작 ([ADR-0002](../adr/0002-target-macos-27.md))
- Mac App Store 배포 ([ADR-0007](../adr/0007-distribution.md))
- 메뉴바 외형 꾸미기, 메뉴바 왼쪽의 앱 메뉴 관리

## 7. 알려진 제약 (M0 검증으로 확인)

| 제약 | 영향 | 대응 |
|---|---|---|
| 앱이 `/Applications`에 있어야 아이콘이 허용 목록과 매칭됨 | 이 앱은 그곳에 설치 필수. 그 밖의 사용자 앱은 숨김 중 표시 불가 | FR-18, 설정 화면에 이유 표시 |
| 제어 센터에서 꺼낸 모듈(타이머 등)은 숨김 중 항상 숨겨짐 | 숨김 상태에서 볼 수 없음 | 설정 화면에 안내. 펼치면 보임 |
| 표시/숨김 단위가 앱 | 한 앱의 아이콘 일부만 숨길 수 없음 | 수용 |
| 허용 목록의 기본이 "차단" | 새 앱 아이콘이 숨겨질 수 있음 | FR-6 (앱 실행 시 목록 갱신) |
| 숨김 중에는 알림 센터가 열리지 않음 | 시계를 눌러도 반응 없음 | 시계를 누르는 순간 숨김을 잠깐 풂 (닫으면 다시 숨김). 트랙패드 쓸기·단축키로 여는 경우는 먼저 펼쳐야 함 ([platform-notes 3.24](../architecture/platform-notes.md)) |
