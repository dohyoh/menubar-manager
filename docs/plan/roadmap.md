## 진행 원칙

1. **위험한 것부터.** 이 프로젝트의 최대 위험은 "macOS 27에서 숨김·순서 변경이 실제로 되는가"입니다. UI보다 먼저 확인합니다.
2. **세로로 자릅니다.** 각 마일스톤 끝에는 직접 써 볼 수 있는 앱이 나옵니다.
3. **안전장치는 기능과 같이.** 숨김 기능을 넣는 순간 복구 장치도 같이 들어갑니다.
4. 규모 표기: **S** 반나절 이내 · **M** 1~2일 · **L** 3일 이상 (1인 기준 대략치).

- [x] 정보 화면 — 주요 기능 설명, 메뉴바 아이콘 옮기는 방법, 버전 (FR-20)

## M2 — 표시/숨김 + 펼치기 + 안전장치

**목표:** 설정에서 숨길 앱을 고르면 메뉴바에서 사라지고, 아이콘 좌클릭으로 펼쳤다 접는다.

- [x] 숨김 백엔드 (`AssessmentModeVisibilityController`) — 허용 목록 적용·교체·해제 ([ADR-0003](../adr/0003-visibility-mechanism.md))
- [x] `MenuBarCoordinator` 상태 머신 + 가짜 백엔드 기반 테스트 (22개)
- [x] 좌클릭 토글 연결, 자동으로 다시 숨기기 타이머 (FR-2)
- [x] 펼친 아이템의 메뉴를 쓰는 동안에는 자동 숨기기를 미루기 (메뉴가 열려 있거나 포인터가 메뉴바 위에 있으면 2초 뒤 다시 확인)
- [x] 앱 목록 수집 (`WorkspaceAppDiscovery`) — 실행 중인 앱 + 설치된 앱(`/Applications`). 접근성 기반 정확 목록은 M0 2차 후
- [x] 설정 > 메뉴바 관리 화면 (FR-17)
  - [x] 앱별 스위치 — 숨김 중이면 즉시 반영
  - [x] 검색, 필터 (실행 중 / 숨긴 앱 / 전체)
  - [x] 표시할 수 없는 앱에 이유 표시 (`/Applications` 밖)
  - [x] 표시/숨김 구역으로 나눠 보여 주기
  - [x] 제어 센터 모듈(타이머 등)이 숨김 중 숨겨진다는 안내를 목록 아래에 표시
- [x] 새 앱 처리 (FR-6) — 앱 실행·종료 알림을 받아 허용 목록 갱신
- [x] 새 앱 정책(표시/숨김/묻기) — 설정 > 일반. "묻기"는 메뉴바 아이콘을 가진 새 앱만 "새로 나타난 앱"에 올림 (접근성 권한 필요. 단위 테스트로 확인, 실제 새 앱으로는 확인하지 않음)
- [x] 안전장치 (FR-5)
  - [x] 숨김을 켜기 전에 설치 위치·시스템 기능 확인. ~~숨김 직후 자기 아이콘 확인~~ 은 불가능으로 판명
  - [x] 자기 자신은 항상 허용. 시스템 아이템은 전부 허용 (개별 숨김은 M4)
  - [x] 종료 시 해제 (크래시 시에는 시스템이 해제 — 검증됨)
  - [x] 숨김 적용 실패 시 전부 표시로 복귀
  - [x] 우클릭 메뉴의 숨기기 스위치를 끄면 전부 표시 유지 (자동으로 다시 숨기지 않음)
  - [x] 응용 프로그램 폴더에서 앱을 다시 열면 설정 창 표시 (아이콘이 안 보일 때의 탈출구)

## M3 — 순서 조정

**전제:** M0 2차의 S5·S6 통과 — 충족.

**목표:** 메뉴바 관리에서 드래그한 순서가 메뉴바에 그대로 반영된다.

- [x] 이동 계획 계산 (`MovePlanner`) — 최소 이동 횟수, 순수 함수 + 테스트 (무작위 200회 포함)
- [x] 접근성 기반 아이템 열거 (`AXItemDiscovery`) — 표시된 아이템만 걸러 냄, 모니터 여러 대 대응
- [x] ⌘+드래그 합성 (`EventSynthesisReorderer`) — 속도 조절 반영
- [x] 순서 조정 흐름 (`OrderingController`) — 잠깐 펼침 → 읽기 → 한 번에 하나씩 이동 → 다시 읽어 확인 → 이전 상태로 복귀. 시스템 아이템은 고정
- [x] 설정 > **순서** 탭 — "메뉴바에서 순서 읽기", 목록 드래그, 적용/되돌리기, 진행·결과 표시
- [x] 접근성 권한 안내 — 순서 탭에서 권한이 없으면 이유와 요청 버튼 표시
- [x] 실패 처리 — 드래그가 두 번 연속 먹지 않으면 중단하고 목록을 실제 순서로 맞춤
- [x] 실제 앱에서 전체 흐름 확인 — Magnet을 옮겼다가 원래 자리로 복구 (명령 채널로 실행)
- [x] 목록에서 마우스로 직접 드래그해 적용 — 사용자가 확인 (2026-11-10)
- [x] "메뉴바 관리" 목록에서 아이콘이 없는 앱 걸러내기 — 접근성 권한이 있으면 "메뉴바" 필터가 기본 (이 Mac: 39개 중 4개)
- [ ] 메뉴바 관리의 표시/숨김 구역 사이 드래그로 표시 여부 바꾸기
- [ ] 폭이 넓은 아이콘 이동의 정확도 확인
- [x] 숨긴 앱의 순서 적용 (FR-3a) — 같은 목록에서 "숨김" 표시와 함께 다룸
- [x] 적용 후 재열거로 검증, 불일치 시 실제 상태로 UI 되돌림
- [x] 이동 불가 아이템(시스템 아이템) 식별·표시
- [x] 사용자가 직접 ⌘+드래그로 바꾼 순서 — 순서를 저장하지 않고 매번 새로 읽으므로 따로 감지할 필요가 없음

**완료 기준:** FR-3·FR-3a 수용 기준 충족 (핵심 흐름 확인됨) · 10개 아이템 무작위 재배열 20회 중 실패 0회 (미실시 — 사용자의 메뉴바를 계속 움직여야 해서 하지 않음)

- [x] 설정 내보내기/가져오기 (FR-9) — 왕복은 단위 테스트로 확인. **파일 선택 창을 거치는 실제 동작은 사용자가 확인 필요**
- [x] 시스템 아이콘 숨김 (FR-19) — Wi-Fi·배터리. 설정 > 메뉴바 관리 목록의 "시스템 아이콘" 구역. 실제 앱에서 Wi-Fi가 숨겨지고 돌아오는 것 확인. 그 밖의 번호는 미확인이라 내놓지 않음
- [x] 화면 언어 선택 (FR-21) — 설정 > 일반의 "언어". 시스템 언어 따르기 / 한국어 / English, 바꾸면 다시 시작해 적용. 설정 사본으로 실행한 빌드에서 영어 전환·복귀, 중국어 환경의 조합을 확인. **설정 창에서 직접 골라 "지금 다시 시작"을 누르는 조작은 사용자 확인 필요**
- [x] 잠자기에서 깨어나면 숨김 다시 적용, 화면 구성이 바뀌면 시계 위치 다시 읽기 (구현만. 실제 잠자기로는 확인하지 않음)
- [x] 검토에서 찾은 문제 수정 (2026-11-10)
  - [x] Dock에 나오지 않는 앱의 실행을 감지하지 못하던 문제 — 실행 중인 앱 목록을 관찰하도록 변경, 실제 앱에서 확인
  - [x] 전체 화면에서 오른쪽 위 클릭을 시계 클릭으로 오인할 수 있던 문제 — 그 자리에 메뉴바가 있는지 확인 (전체 화면 앱에서의 실제 동작은 미확인)
  - [x] 설정 파일을 읽지 못하면 기본값으로 덮어쓰던 문제 — `state.unreadable.json`으로 사본을 남김. 더 새로운 형식의 파일은 읽거나 가져오지 않음
  - [x] 단축키 표시가 입력 소스(한글)를 따르던 문제 — 키 위치로 표시
  - [x] 단축키 기록 중 창을 닫으면 기록 상태가 남던 문제
  - [x] "묻기" 정책에서 새 앱 아이콘이 몇 초 늦게 나타나던 문제 — 허용 목록부터 갱신
  - [x] 정보 화면에 전역 단축키·알림 센터·시스템 아이콘 설명 추가
  - [x] 보안: 서명에 강화된 런타임, Debug 전용 명령 채널은 실행 인자로만, 평소에는 Release 설치
- [x] 설정의 진단을 별도 탭으로 분리 (2026-11-11)
- [x] "순서" 탭을 "메뉴바 관리"의 "순서 편집"으로 합침 (2026-11-11) — 화면 전환·취소·탭 이동은 확인. **목록을 끌어 "적용"하는 조작은 사용자가 확인 필요**
- [x] 메뉴바 관리를 열 때 다른 앱이 잠깐 보이던 문제, 목록 아래 빈 칸 수정 (2026-11-11)
- [x] 알림 센터를 닫으면 곧바로 다시 숨김 (2026-11-11) — 닫는 클릭 뒤 약 0.3~0.4초. 숨긴 채로 알림 센터를 여는 것은 시스템 구조상 불가능함을 확인
- [ ] 접근성 권한이 없을 때, 알림 센터를 닫은 뒤 다시 숨기기가 늦어짐 (닫아도 창이 한동안 남음 — [platform-notes 3.24](../architecture/platform-notes.md))

- [ ] 사용자 전환 후 상태 점검
- [ ] 로그 (`os.Logger`)
- [ ] 트랙패드 쓸기·단축키로 여는 알림 센터 (숨김 중에는 열리지 않음 — 방법 조사)
