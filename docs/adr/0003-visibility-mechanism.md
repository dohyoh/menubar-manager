# ADR-0003: 숨김 방식 — 시스템 허용 목록 (Assessment Mode)

- 상태: ✅ 채택 (2026-11-10 M0 검증 S1·S2·S4 통과)
- 날짜: 2026-11-10
- 관련: [platform-notes.md](../architecture/platform-notes.md) · [ADR-0005](0005-backend-abstraction-private-api.md) · [ADR-0010](0010-install-location.md)

## 맥락

FR-1(표시할 앱 선택)과 FR-2(펼치기/숨기기)를 구현하려면 다른 앱의 메뉴바 아이템을 숨기고 다시 보이게 할 수단이 필요합니다. macOS에는 이를 위한 공개 API가 없습니다.

macOS 26까지 널리 쓰인 "구분자 확장" 기법은 macOS 27에서 막힌 것으로 보고됩니다. 한편 macOS 27의 비공개 프레임워크 `MenuBarClientCore`에는 허용할 번들 ID 목록을 받아 메뉴바 표시를 제한하는 클래스(`MBAssessmentModeConfiguration`, `MBAssessmentModeAssertion`)가 있습니다.

## 결정

**시스템 허용 목록 방식을 사용합니다.**

- 숨김 적용 = "표시할 앱의 번들 ID + 이 앱 자신 + 시스템 아이템 번호"로 구성한 허용 목록을 활성화
- 펼치기 = 제한 해제, 숨기기 = 다시 활성화
- 표시/숨김의 단위는 **앱(번들 ID)**
- 목록 변경은 **새 assertion을 켠 뒤 이전 것을 해제**하는 방식으로 교체. 동시에 1개만 유지

## 검증 결과 (2026-11-10, macOS 27.2.1)

| 확인한 것 | 결과 |
|---|---|
| 일반 앱에서 활성화 (entitlement 없음, 임시 서명 포함) | ✅ 동작 |
| 목록 밖 앱 아이콘이 사라짐, 1초 내 반영 | ✅ |
| `invalidate`·정상 종료·`SIGKILL` 모두에서 자동 복구 | ✅ |
| 시스템 아이템 번호로 시스템 아이콘도 개별 제어 (배터리 0, 시계 2, Wi-Fi 6, 제어 센터 8) | ✅ |
| 자기 아이콘 유지 | ✅ 단, 앱이 `/Applications`에 있어야 함 |
| 깜빡임 없는 목록 교체 | ✅ |

상세는 [platform-notes.md 3절](../architecture/platform-notes.md#3-이-mac에서-직접-확인한-것-).

## 검토한 대안

| | 방식 | 판단 |
|---|---|---|
| **A** | **시스템 허용 목록** (비공개 `MBAssessmentModeAssertion`) | **채택** — 검증 통과 |
| B | 시스템 설정 "메뉴 막대에서 허용" 값을 변경 | 저장소가 보호되어 접근 불가 확인 → 기각 |
| C | 각 앱의 `NSStatusItem Visible …` 설정 키 변경 | 남의 앱 설정을 고침, 재시작 필요 → 기각 |
| D | 구분자 확장 (macOS 26까지의 표준 기법) | macOS 27에서 차단된 것으로 보고됨 → 기각 |
| E | 숨기지 않고 시스템 넘침 화살표에 맡김 | 무엇이 접힐지 고를 수 없음 → 기각 |

## 결과

**얻는 것**
- 설정 화면의 토글 ↔ 허용 목록이 1:1로 대응해 모델이 단순합니다.
- 숨김에 화면 좌표·이벤트 합성·접근성 권한이 필요 없습니다. **FR-1·FR-2는 권한 없이 동작합니다.**
- 크래시해도 시스템이 복구해 주므로 fail-open이 구조적으로 보장됩니다.

**감수하는 것 (검증으로 확인된 제약)**
- 비공개 API 의존 → 격리·자가진단으로 대응 ([ADR-0005](0005-backend-abstraction-private-api.md)).
- **기본이 "차단"입니다.** 목록에 없는 앱은 숨겨지므로, 새 앱이 실행되면 허용 목록을 갱신해야 합니다 (앱 실행 알림 → 목록 재적용).
- **`/Applications` 밖의 앱은 숨김 중 표시할 수 없습니다.** 이 앱 자신도 `/Applications`에 설치해야 합니다 ([ADR-0010](0010-install-location.md)).
- **제어 센터 모듈 아이템(타이머 등)은 숨김 중 항상 숨겨집니다.** 설정 화면에 안내합니다.
- 한 앱의 여러 아이템 중 일부만 숨길 수 없습니다.
- Mac App Store 배포 불가 ([ADR-0007](0007-distribution.md)).

**남은 확인:** 숨김 중 알림 센터·제어 센터 클릭 동작(S3).
