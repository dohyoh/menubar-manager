# ADR-0013: macOS 26 이하의 시스템 아이콘 숨김 — 메뉴바에서 읽어, 옮겨서 숨김

- 상태: ✅ 채택 (2026-11-11 사용자 요청, macOS 26.5.2에서 실제 앱으로 확인)
- 날짜: 2026-11-11
- 관련: [ADR-0012](0012-separator-visibility-macos26.md) (결정 6의 "시스템 아이콘 숨김은 내놓지 않는다"를 대체) · [ADR-0004](0004-reorder-mechanism.md) · [platform-notes.md 7.12](../architecture/platform-notes.md#712-시스템-아이콘-옮기기)

## 맥락

[ADR-0012](0012-separator-visibility-macos26.md)는 macOS 26 이하의 숨김을 앱 단위로만 내놓고 시스템 아이콘은 범위에서 뺐습니다. 써 보니 배터리·입력 소스·Siri 같은 시스템 아이콘을 숨길 수 없는 것이 기능 누락으로 느껴졌습니다 (macOS 27에서는 Wi-Fi·배터리를 숨길 수 있음).

구분자 방식에서 무언가를 숨기려면 그 아이콘을 구분자 왼쪽으로 옮겨야 합니다. 지금까지는 "시스템 아이템은 옮기지 않는다"([ADR-0004](0004-reorder-mechanism.md), 순서 조정)를 숨김에도 그대로 적용하고 있었습니다.

## 결정

**macOS 26 이하에서는 메뉴바에서 읽은 시스템 아이콘 중 옮길 수 있는 것을 숨길 수 있게 하고, 숨길 때는 앱 아이콘과 같은 방법(⌘+드래그 합성)으로 구분자 왼쪽에 옮깁니다.**

1. **고를 수 있는 아이콘은 메뉴바에서 읽습니다.** macOS 27처럼 정해진 목록(Wi-Fi·배터리)이 아니라, 지금 메뉴바에 있는 시스템 아이콘을 접근성으로 읽어 설정의 "시스템 아이콘" 구역에 보여 줍니다.
2. **아이콘은 키로 가리킵니다.** 제어 센터가 그리는 아이콘은 접근성 식별자(`com.apple.menuextra.battery` 등), 식별자가 없는 것(입력 소스, Siri)은 그 프로세스의 번들 ID. 화면에 보이는 이름은 언어·상태에 따라 바뀌어 키로 쓰지 않습니다.
3. **시계와 제어 센터는 숨기지 않습니다.** macOS가 자리를 고정해 둬서 옮겨지지 않습니다 (검증됨). 목록에도 내놓지 않습니다.
4. **설정은 따로 저장합니다** (`Layout.hiddenSystemItemKeys`). macOS 27의 `hiddenSystemItems`(번호)와는 가리키는 수단이 달라 서로 바꿔 쓸 수 없습니다.
5. **다시 표시할 때는 원래 자리로 돌려놓습니다.** 숨길 때 그 아이콘의 오른쪽 이웃을 기억해 뒀다가, 표시로 바꾸면 그 이웃의 앞에 놓습니다. 이웃도 숨겨져 있으면 그 이웃의 이웃을 따라갑니다. 앱 아이콘에도 같은 규칙을 적용합니다. 기억은 앱이 실행 중인 동안만 유지합니다.
6. 순서 편집에서는 지금처럼 시스템 아이콘을 옮기지 않습니다 (ADR-0004 그대로).

## 검증 결과 (2026-11-11, macOS 26.5.2)

| 확인한 것 | 결과 |
|---|---|
| 배터리 · Wi-Fi · 입력 소스 · Siri를 구분자 왼쪽으로 옮기고 원래 자리로 되돌리기 (검증용 앱) | ✅ 모두 옮겨짐 |
| 제어 센터 · 시계 | ❌ 옮겨지지 않음 — 숨길 수 없음 |
| 실제 앱에서 네 아이콘을 차례로 숨김 | ✅ 하나에 약 3초 |
| 실제 앱에서 다시 표시 → 기억해 둔 이웃 앞으로 | ✅ Wi-Fi·입력 소스는 한 번에 제자리. Siri는 첫 드래그가 먹지 않아 구분자 옆에 놓였음 → 같은 자리를 한 번 더 시도하도록 고침 |
| 이웃이 숨겨져 있을 때 (배터리의 이웃 Siri가 숨김 상태) | 구분자 옆에 놓였음 → 이웃의 이웃을 따라가도록 고침 |
| 설정 창의 시스템 아이콘 구역 | ✅ 입력 소스 · Wi-Fi · 배터리 · Siri |

고친 두 가지는 단위 테스트로만 확인했습니다. 상세는 [platform-notes 7.12](../architecture/platform-notes.md#712-시스템-아이콘-옮기기).

## 검토한 대안

| 대안 | 판단 |
|---|---|
| 시스템 아이콘은 계속 숨기지 않는다 | 사용자 요청과 맞지 않음. macOS 27과의 기능 차이도 커짐 → 기각 |
| macOS 27과 같은 정해진 목록(Wi-Fi·배터리)만 | 입력 소스·Siri처럼 실제로 숨기고 싶은 것이 빠짐. 번호가 아니라 식별자로 가리켜야 해서 어차피 다른 구현 → 기각 |
| 원래 자리를 기억하지 않고 구분자 옆에 놓는다 | 구현은 단순하지만, 배터리를 숨겼다 표시하면 메뉴바 왼쪽 끝으로 가 버림. 시스템 아이콘은 자리가 익숙해서 더 거슬림 → 기각 |
| 원래 자리를 설정 파일에 저장 | 재시작 뒤에도 돌려놓을 수 있지만, 그사이 메뉴바가 바뀌면 틀린 자리가 됨 → 나중에 검토 |

## 결과

**얻는 것**
- macOS 26 이하에서도 배터리·Wi-Fi·입력 소스·Siri 등 시스템 아이콘을 숨길 수 있습니다.
- 숨겼다가 표시해도 아이콘이 원래 자리로 돌아옵니다 (앱 아이콘 포함).

**감수하는 것**
- 숨김을 위해서는 시스템 아이콘도 앱이 옮깁니다. ADR-0004의 "시스템 아이템은 옮기지 않는다"는 순서 편집에만 남습니다.
- 시계와 제어 센터는 숨길 수 없습니다. macOS가 고정해 둔 아이콘이 더 있을 수 있고, 그런 아이콘은 세 번 해 보고 그 실행 동안 건너뜁니다.
- 원래 자리의 기억은 앱을 다시 실행하면 사라집니다. 그 뒤에 표시로 바꾼 아이콘은 구분자 바로 오른쪽(표시된 아이콘의 왼쪽 끝)에 놓입니다.
- 숨기기로 하지 않은 시스템 아이콘이 구분자 왼쪽에 있으면 표시 쪽으로 옮깁니다. 사용자가 직접 ⌘+드래그로 왼쪽에 놓아 둔 것도 설정에 맞춰 되돌립니다.
- 시스템 아이콘의 키는 macOS 26.5.2에서 읽은 값입니다. 다른 버전에서 식별자가 다르면 그 버전에서 다시 골라야 합니다.
