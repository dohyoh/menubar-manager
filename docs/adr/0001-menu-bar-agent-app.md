# ADR-0001: 제품 형태 — WidgetKit 위젯이 아닌 메뉴바 상주 앱

- 상태: ✅ 채택 (단, "패널" 부분은 [ADR-0009](0009-interaction-model.md)로 대체됨)
- 날짜: 2026-11-10
- 관련: [requirements.md](../plan/requirements.md)

## 맥락

요구사항은 "메뉴바를 관리하는 위젯"입니다. macOS에서 "위젯"은 보통 WidgetKit으로 만든, 데스크탑·알림 센터에 놓는 위젯을 뜻합니다. 그런데 WidgetKit 위젯은 샌드박스 안의 확장으로 실행되고, 다른 앱의 메뉴바 아이템을 조회하거나 바꿀 수단이 없습니다. 상시 실행도 보장되지 않습니다.

## 결정

**Dock 아이콘 없이 메뉴바에 상주하는 일반 앱(`LSUIElement` 에이전트)** 으로 만듭니다. 메뉴바의 자기 아이콘을 누르면 열리는 **패널**이 요구사항의 "위젯" 역할을 합니다.

## 검토한 대안

| 대안 | 장점 | 단점 | 판단 |
|---|---|---|---|
| WidgetKit 위젯 | 시스템 위젯 갤러리에 통합 | 메뉴바 제어 불가, 샌드박스, 상시 실행 불가 | 불가 |
| 일반 창 앱 (Dock 아이콘 있음) | 구현 단순 | 상시 실행 도구에 Dock 아이콘은 방해. 메뉴바 도구는 메뉴바에 있는 것이 자연스러움 | 기각 |
| **메뉴바 상주 앱 + 패널** | 항상 접근 가능, 관리 대상 바로 옆에 UI | 자기 아이콘이 메뉴바 공간 1칸 차지 | **채택** |

## 결과

- 이 앱의 아이콘은 항상 표시되어야 합니다 → 허용 목록에 자기 자신을 반드시 포함 (보호 대상).
- 설정처럼 넓은 화면이 필요한 UI는 별도 창으로 엽니다.
- 나중에 "잠깐 보기"를 제어 센터 컨트롤이나 WidgetKit 위젯 버튼으로 노출하는 것은 가능합니다 (App Intent로 본 앱에 요청). 필요해지면 별도 ADR로 다룹니다.
