## 상태

| 상태 | 뜻 |
|---|---|
| 🟡 제안 | 방향은 잡았으나 검증 또는 사용자 확인이 남음 |
| ✅ 채택 | 확정. 이대로 구현 |
| ♻️ 대체됨 | 새 ADR로 바뀜 (본문 상단에 후속 ADR 링크) |
| ❌ 폐기 | 더 이상 유효하지 않음 |

## 작성 규칙

1. 파일명: `NNNN-kebab-case-제목.md`. 번호는 순차 증가, 재사용하지 않습니다.
2. **채택된 ADR의 결정 내용은 고치지 않습니다.** 바뀌면 새 ADR을 쓰고, 이전 ADR의 상태를 `대체됨`으로 바꿉니다. (오탈자·링크 수정은 예외)
3. `제안` 상태의 ADR은 검증 결과에 따라 직접 수정해 `채택`으로 올릴 수 있습니다.
4. 추가·상태 변경 시 이 목록과 [overview.html](../overview.html)의 결정 표를 함께 갱신합니다.
5. 짧게 씁니다. 한 화면 안에 맥락·결정·결과가 들어오는 것이 목표입니다.
