### 추가 — 순서 조정, M3 (2026-11-10)
- 설정 창에 **"순서" 탭**: "메뉴바에서 순서 읽기"로 현재 순서를 가져오고, 목록을 드래그해 바꾼 뒤 "적용"하면 메뉴바 아이콘이 그 순서로 옮겨짐. 숨긴 앱도 포함. 시스템 항목은 고정.
- 접근성 권한이 없으면 순서 탭에 이유와 요청 버튼 표시.
- 모니터가 두 대일 때 좌표가 섞여 순서가 뒤섞이던 문제를 모니터 오른쪽 끝 기준 거리로 정규화해 해결.
- 접근성 권한이 재빌드 후에도 유지되도록 빌드 후 고정 인증서로 다시 서명.

### 수정 — 알림 센터 (2026-11-10)
- **숨김 중에 시계를 눌러도 알림 센터가 열리지 않던 문제.** 시계를 누르는 순간 숨김을 잠깐 풀어 알림 센터가 열리게 하고, 닫으면 2초 안에 다시 숨김. 아주 빠른 클릭은 한 번 더 눌러 보완(접근성 권한이 있을 때).
- 한계: 트랙패드 두 손가락 쓸기나 단축키로 여는 경우는 숨김 중에 열리지 않음 (먼저 좌클릭으로 펼치기).

### 추가 — 안정화·편의, M4 (2026-11-10)
- **전역 단축키**: 설정 > 일반에서 "숨긴 앱 펼치기 / 숨기기"와 "설정 열기"에 키 조합을 기록. 등록에 실패한 조합은 화면에 표시.
- **시스템 아이콘 숨김**: 설정 > 메뉴바 관리 목록 아래쪽의 "시스템 아이콘" 구역에서 Wi-Fi·배터리를 끄면 숨기기가 켜져 있는 동안 함께 숨김. (처음에는 일반 탭에 두었다가, 앱과 같은 자리에서 고르도록 메뉴바 관리로 옮김)
- **설정 백업**: 숨길 앱 목록과 옵션을 파일로 내보내고 가져오기.
- **진단**: 설정 > 일반 > 진단에 앱·macOS 버전, 상태, 숨김 기능·설치 위치·접근성 권한 등을 표시하고 복사.
- **메뉴바 관리의 "메뉴바" 필터**: 접근성 권한이 있으면 메뉴바 아이콘을 가진 앱만 먼저 보여 줌 (없으면 이전처럼 "실행 중"부터).
- **새 앱 정책 "묻기"**: 메뉴바 아이콘을 가진 새 앱을 "새로 나타난 앱"에 올리고 [표시]/[숨김]을 고르게 함. 정할 것이 있으면 메뉴바 아이콘 옆에 점, 우클릭 메뉴에 "새로 나타난 앱 N개…".
- **응용 프로그램 폴더로 옮기기 버튼**: 다른 위치에서 실행했을 때의 안내 창에서 바로 옮기고 다시 실행.
- 잠자기에서 깨어나면 숨김을 다시 적용.
- 단위 테스트 71개. 문자열 136개(영어 번역 포함).

### 보안 (2026-11-10)
- 고정 인증서로 서명할 때 **강화된 런타임**을 켬. 다른 프로세스가 라이브러리를 끼워 넣어 이 앱의 접근성 권한을 빌려 쓰는 것을 막음.
- Debug 빌드의 자동 검증용 명령 채널은 **실행 인자**(`-automationDir`)로만 켜지게 함 (저장된 기본값으로는 켜지지 않음). Release 빌드에는 이 채널이 들어가지 않음.
- 평소에 쓰는 앱은 Release로 설치하도록 안내 추가 (`CONFIG=Release ./scripts/build.sh install`).

### 검증 (M0 2차, 2026-11-10)

- 확인하지 못한 것: 숨김 중 시계를 눌러 알림 센터 열기.

### 수정
- 2026-11-10 — 우클릭 메뉴의 "숨기기" 스위치가 켜져도 회색으로 보이던 문제. 시스템 스위치가 메뉴 안에서는 비활성 색으로 그려지기 때문이며, 켜짐을 강조색으로 그리는 스위치로 교체.
- 2026-11-10 — 숨기기를 끄면 메뉴바 아이콘이 빈 네모로 바뀌던 문제. "숨기기 꺼짐"에 별도 아이콘을 배정했던 것을 없애고 펼침과 같은 모양(왼쪽 절반이 채워진 네모)으로 통일. 숨김을 켤 수 없는 상태(설치 위치·미지원)만 느낌표 네모로 구분.
- 2026-11-10 — 메뉴의 "숨기기" 줄은 글자 부분을 눌러도 스위치가 바뀜.

### 결정 (3차)
- 2026-11-10 — ADR-0002 확정: 앱은 macOS 15부터 실행, 숨김은 시스템 기능이 있는 버전에서만 (사용자 방침 "큰 수정 없는 한도 내 지원"). ADR-0006 확정 (XcodeGen).
- 2026-11-10 — "숨김 직후 자기 아이콘 확인" 안전장치는 불가능으로 판명되어 설치 위치 사전 확인 + 앱 다시 열기 탈출구로 대체 (ADR-0010에 기록).

### 아직 안 된 것

### 변경
- 2026-11-10 — 상호작용 모델 변경 (사용자 요구). 패널을 없애고 **좌클릭 = 펼치기/숨기기, 우클릭 = 간단한 옵션 + 설정, 앱 관리는 설정 창의 "메뉴바 관리"** 로 ([ADR-0009](adr/0009-interaction-model.md)). 요구사항에 FR-16(우클릭 메뉴), FR-17(설정 창 관리), FR-18(설치 위치 확인), FR-19(시스템 아이템 숨김) 추가. FR-6(새 앱 처리)을 P0으로 상향.

- 2026-11-10 — 우클릭 메뉴 구성 변경 (사용자 요구). "숨기기"를 **스위치**로 바꾸고, "펼친 뒤 자동으로 다시 숨기기"를 메뉴에서 **설정 창으로** 옮김. "관리 일시 중지"는 스위치 끔이 대신함. 검증용 앱과 FR-16, ADR-0009에 반영.

- 2026-11-10 — 우클릭 메뉴에 **"정보"** 추가 (사용자 요구). 주요 기능을 간략히 설명하는 화면을 열며, 메뉴바 아이콘 옮기는 방법(⌘+드래그)을 포함. FR-20 신설, 검증용 앱에 구현.

### 검증 (M0 1차)
- 2026-11-10 — 수동 ⌘+드래그로 메뉴바 아이콘 순서가 바뀜을 사용자가 직접 확인. "정보" 화면의 안내가 유효함. 프로그램에 의한 순서 변경(S6)은 여전히 미확인.
- 2026-11-10 — 허용 목록 방식 숨김이 macOS 27.2.1에서 동작함을 확인. 권한 불필요, 해제·강제 종료 시 자동 복구, 깜빡임 없는 목록 교체, 시스템 아이템 번호(배터리 0, 시계 2, Wi-Fi 6, 제어 센터 8).
- 2026-11-10 — 새로 발견한 제약: ① 앱이 `/Applications`에 있어야 아이콘이 허용 목록과 매칭됨 ② 제어 센터 모듈 아이템(타이머 등)은 숨김 중 항상 숨겨짐 ③ 시스템의 추적 앱 목록은 읽을 수 없음.
- 2026-11-10 — 아이콘 좌클릭(토글)/우클릭(메뉴)이 구분되어 동작함을 사용자의 실제 클릭으로 확인.
- 2026-11-10 — 미검증으로 남음: 접근성 기반 아이템 열거, 순서 변경, 숨김 중 알림 센터 동작 (접근성 권한 허용 필요).
